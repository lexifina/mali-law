# Article 3
1. L’agrément de commissionnaire en douane est donné à titre personnel.
2. Les personnes morales doivent obtenir l’agrément pour elles mêmes.
3. Les personnes habilitées à représenter les sociétés auprès de l’Administration des Douanes sont les suivantes :
a) Pour les sociétés en nom collectif ;
- Soit le ou les gérants, - Soit les associés en nom collectif.
b) Pour les sociétés anonymes :
- Soit le président Directeur Général ou le Directeur Général,
- Soit l’Administrateur délégué ou un membre du Directoire.
c) Pour les sociétés à responsabilité limitée :
- Le ou les gérants.
d) Pour les groupements d’intérêt économique :
- Le ou les administrateurs en douanes délégués par les contrats de groupement ou par les membres.
