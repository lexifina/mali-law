# Article 3
L’établissement délivrera les diplômes suivants :
- Le BTS (le Brevet de Technicien Supérieur), deux années d’études après le baccalauréat (BAC+2) ;
- Le DTS (le diplôme de Technicien Supérieur), deux années d’études après le baccalauréat (BAC+2) ;
- La Licence professionnalisée, trois années d’études après le baccalauréat (BAC+3) ;
- La Maîtrise professionnalisée, quatre années d’études après le baccalauréat (BAC+4) ;
- Le Master, cinq années d’études après le baccalauréat (BAC+5) ;
