# Article 2
L’Ecole Supérieure de Management, de Commerce d’Information délivrera les diplômes suivants :
- Technicien Spécialisé, deux années d’études après le baccalauréat (BAC+2) ;
- Licence professionnalisée, trois années d’études après le baccalauréat (BAC+3) ;
- Le Master, cinq années d’études après le baccalauréat (BAC+5) ;
- Le DESS, cinq années d’études après le bac (BAC+5) ;
