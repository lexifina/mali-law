# Article 1er
Monsieur Aliou DIABY, est autorisé à ouvrir, à Kati, un établissement privé d’Enseignement technique et professionnel en agro-pastoral dénommé « Institut Polytechnique Rokia DOUCOURE de Kati », en abrégé IPRD avec les filières suivantes :
CYCLE CAP :
- Machinisme agricole ;
- Agriculture ;
- Foresterie ;
- Elevage.
CYCLE BT :
- Agriculture ;
- Elevage ;
- Foresterie ;
- Irrigation ;
- Environnement.
