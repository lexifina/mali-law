# Article 3
L’Université Africaine de Management, des Sciences Appliquées et de Télécommunications, délivres les diplômes suivants :
- le DUT, deux années après le baccalauréat (BAC+2) ;
- la Licence, six semestres d’études après le baccalauréat (BAC+3) ;
- le Master, quatre semestres d’études après la Licence (BAC+5).
