# Article 3
L’Ecole Supérieure d’Informatique et de Gestion délivre les diplômes suivants :
- le DUT, soit deux années d’études après le baccalauréat (BAC + 2) ;
- la Licence, soit trois années d’études après le baccalauréat (BAC + 3) ;
- le Master, soit cinq années d’études après le baccalauréat (BAC+5).
