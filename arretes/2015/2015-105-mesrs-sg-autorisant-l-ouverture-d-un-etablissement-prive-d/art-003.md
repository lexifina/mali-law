# Article 3
Le Centre Privé d’Enseignement Supérieur de Kalabancoro, délivre les diplômes suivants :
- le DUT, quatre semestres d’études après le baccalauréat (BAC+2) ;
- la Licence, six semestres d’études après le baccalauréat (BAC+3) ;
- le Master, quatre semestres d’études après la Licence (BAC+5).
