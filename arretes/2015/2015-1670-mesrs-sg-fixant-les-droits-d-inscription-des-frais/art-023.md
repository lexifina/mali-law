# Article 23
Les étudiants payent obligatoirement les droits d’inscription et les frais pédagogiques fixés comme suit :
Pour les Maliens non boursiers :
- Frais pédagogiques : 300.000 FCFA par an ;
- Droits d’inscription : 150.000 FCFA par an.
Pour les Maliens boursiers et les non Maliens :
- Frais pédagogiques : 600 000 FCFA par an ;
- Droits d’inscription : 300.000 FCFA par an.
