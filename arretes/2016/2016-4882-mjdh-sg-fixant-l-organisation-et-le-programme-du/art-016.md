# Article 16
Le programme des épreuves orales est le suivant :
1) Epreuve portant sur des aspects sociaux-juridiques, économiques et culturels du monde actuel :
Cette épreuve n’a pas de programme limitatif.
2) Epreuve portant sur le droit commercial :
- Les actes de commerce ;
- Les commerçants ;
- Le fonds de commerce ;
- Le règlement judiciaire et la liquidation judiciaire.
3) Epreuve portant sur le droit des sûretés :
- Le cautionnement ;
- Les garanties et contre-garantie autonome ;
- Les sûretés réelles mobilières ;
- Les hypothèques.
