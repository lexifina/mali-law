# Article 4
Les poids sont repartis en neuf (9) classes : E1, E2, F1, F2, M1, M1-2, M2, M2-3 et M3, suivant leur degré de précision :
- Précision E1 : spéciale ;
- Précision E2 : fine (2ème échelon) ;
- Précision F1 : fine (1er échelon) ;
- Précision F2 : moyenne ou commerciale ;
- Précision M1 : ordinaire ;
- Précision M1-2 : ordinaire ;
- Précision M2 : courante (2ème échelon) ;
- Précision M2-3 : courante (2ème échelon) - Précision M3 : courante (1er échelon).
Pour les poids en service, la différence maximale tolérée entre la masse nominale et la masse conventionnelle est déterminée par la Recommandation n° 76 (R76) de l’Organisation Internationale de Métrologie Légale (OIML) en vigueur.
