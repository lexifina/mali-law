# Article 8
La Commission nationale du médicament examine et valide les travaux du Comité d’experts et donne un avis sur :
- les dossiers de demande d’autorisation de mise sur le marché ;
- les suspensions temporaires d’autorisation de mise sur le marché ;
- les projets de retraits définitifs de l’autorisation de mise sur le marché ;
- les variations de l’autorisation de mise sur le marché ; - les transferts de l’autorisation de mise sur le marché.
