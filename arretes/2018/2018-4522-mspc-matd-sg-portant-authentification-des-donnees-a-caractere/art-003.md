# Article 3
Données consultées
Les données à caractère personnel utilisées dans le contrôle sont :
1.
le Numéro d’Identification Nationale (NINA) ;
2.
le Numéro d’identification RAVEC ;
3.
les prénom(s) ;
4.
le nom) ;
5.
la Date de naissance ;
6.
le sexe ;
7.
les empreintes ;
8.
les prénom(s) et nom du père ;
9.
les prénom(s) et nom de la mère ;
10.
le lieu de naissance (région, cercle, commune, village, fraction ou quartier).
Les données à caractère personnel contenues sur la carte NINA ou la Fiche Descriptive Individuelle ne sont pas conservées par la plateforme d’accès aux données du registre national.
