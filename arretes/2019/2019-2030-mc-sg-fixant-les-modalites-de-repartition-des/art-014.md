# Article 14
Les bénéficiaires de la répartition sont :
- pour les œuvres musicales: l’auteur, le compositeur, le parolier, le chanteur (interprète), l’adaptateur, l’arrangeur, l’éditeur, le sous éditeur, l’instrumentiste, le choriste, le chorégraphe, le producteur de phonogramme et de vidéogramme ;
- les œuvres littéraires :l’auteur, le traducteur, l’adaptateur, l’éditeur, le narrateur, le conteur, le déclamateur, le metteur en scène, l’illustrateur, le photographe ;
- pour les œuvres dramatiques, dramatico-musicales, interprétations et exécutions audiovisuelles, cinématographiques : l’auteur, le traducteur, l’adaptateur, le narrateur,le scénariste, le dialoguiste, le chorégraphe, le réalisateur, l’acteur, le comédien ;
- pour les œuvres d’art : le sculpteur, le dessinateur, le peintre, le photographe, l’architecte, l’éditeur, l’adaptateur, l’auteur de copie.
