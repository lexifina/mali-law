# Article 37
La répartition des redevances est effectuée sur la base de la documentation sur les personnes ayant participé à la création de l’œuvre musicale ou à sa publication, à savoir :
- le compositeur ;
- l’auteur ;
- le parolier ;
- l’adaptateur ;
- l’arrangeur ;
- l’éditeur ;
- le sous éditeur ;
- les artistes interprètes ou exécutants ;
- les producteurs.
