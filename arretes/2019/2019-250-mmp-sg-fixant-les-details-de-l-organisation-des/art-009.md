# Article 9
La gestion des candidatures se déroule en cinq étapes :
- une étape de quinze jours pour l’enregistrement des candidatures ;
- une étape de deux jours pour la publication des listes de candidatures déposées ;
- une étape de deux jours pour l’exercice du recours contentieux ;
- une étape de huit jours pour la gestion du contentieux ;
- une étape de deux jours pour la publication des listes définitives de candidats.
