# Article 2
Le Groupement Mixte de Gendarmerie de Ménaka comprend :
- L’Escadron 11/1 de Ménaka ;
- L’Escadron 11/2 d’Anderamboukane ;
- L’Escadron 11/3 d’Anouzagrène ;
- L’Escadron 11/4 d’Ifourkarétane ;
- L’Escadron 11/5 d’In Délmane ;
- L’Escadron 11/6 d’Inchinanane ;
- L’Escadron 11/7 d’Inékar ;
- L’Escadron 11/8 de Tamalet ;
- L’Escadron 11/9 de Téguerert ;
- L’Escadron 11/10 de Tidermène ;
- La Compagnie Territoriale de Gendarmerie de Ménaka.
