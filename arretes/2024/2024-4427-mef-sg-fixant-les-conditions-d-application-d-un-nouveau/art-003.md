# Article 3
L’application du nouveau tarif plus favorable ne peut être accordée dans les cas suivants :
a) les marchandises constituées en dépôt pour les raisons ci-après :
- les marchandises qui, à l’importation, n’ont pas été déclarées en détail dans le délai légal de trois (03) jours francs ou de trente (30) jours pour les marchandises placées dans les Magasins et Aires de Dédouanement ;
- absence de vérification des marchandises déclarées ;
- non-paiement des droits et taxes liquidés dans le délai requis ;
b) les marchandises faisant l’objet d’un contentieux avec la douane ;
c) les marchandises pour lesquelles l’autorisation d’enlèvement a déjà été accordée par le bureau des douanes ;
d) les marchandises pour lesquelles les droits et taxes ont été acquittés.
