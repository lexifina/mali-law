# Article 131-3
Les peines applicables aux délits sont :
1°) l’emprisonnement pour une durée n’excédant pas dix ans ;
2°) l’emprisonnement pour une durée n’excédant pas sept ans ;
3°) l’emprisonnement pour une durée n’excédant pas cinq ans ;
4°) l’emprisonnement pour une durée n’excédant pas trois ans ;
5°) l’emprisonnement pour une durée n’excédant pas deux ans ;
6°) l’emprisonnement pour une durée n’excédant pas un an ;
7°) l’emprisonnement pour une durée n’excédant pas six mois ;
8°) l’emprisonnement pour une durée n’excédant pas trois mois;
9°) la peine de travail d’intérêt général ;
10°) l’amende ;
11°) les peines complémentaires prévues à l’article 131-6 ci-dessous.
La peine d’un jour d’emprisonnement est de vingt-quatre heures. Celle d’un mois est de trente jours. Celle d’un an est de douze mois.
