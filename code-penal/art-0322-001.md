# Article 322-1
Quiconque s’introduit sans droit et à l’aide de menaces ou de violences dans le domicile d’un citoyen, est puni d’un emprisonnement de trois mois.
Si le coupable est un fonctionnaire au sens du présent Code agissant hors les cas prévus par la loi, la peine est d’un an d’emprisonnement.
Les Juges peuvent, en outre, prononcer l’amende de 120 000 francs.
La violence n’est pas nécessaire si l’auteur de la violation s’introduit chez autrui dans le but de le provoquer.
