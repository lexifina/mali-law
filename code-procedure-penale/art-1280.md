# Article 1280
Les peines portées par un arrêt ou un Jugement rendu pour une contravention de police se prescrivent par deux années révolues à compter de la date où cet arrêt ou Jugement est devenu définitif.
Toutefois, les peines prononcées pour une contravention de police connexe à un délit se prescrivent selon les dispositions de l’article 1279 du présent Code.
