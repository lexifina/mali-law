# Article 226
Un interprète est commis dans les mêmes conditions lorsque le témoin est atteint de surdité, pour traduire en langue des signes ou toute méthode permettant de communiquer avec les sourds.
Si le témoin atteint de surdité sait lire et écrire, le Juge d’Instruction peut également communiquer avec lui par écrit.
