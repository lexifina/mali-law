# Article 287
Lorsqu’au Cours de l’information, il intervient un changement de qualification de crime à délit alors que l’inculpé est détenu sous le régime criminel, le maintien en détention provisoire ne peut être ordonné que dans les conditions prévues en matière correctionnelle.
En cas de requalification de délit à crime, il est décerné contre l’inculpé dans les formes prévues à l’article 284 du présent Code un autre mandat de dépôt portant la nouvelle inculpation criminelle.
