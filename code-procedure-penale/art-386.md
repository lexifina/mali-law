# Article 386
La Chambre de Contrôle de l’Instruction statue par l’arrêt portant qu’il n’y a lieu à suivre sur la restitution des objets saisis ; elle demeure compétente pour statuer éventuellement sur cette restitution postérieurement à l’arrêt de non-lieu.
Elle peut refuser la restitution lorsque celle-ci présente un danger pour les personnes ou les biens.
