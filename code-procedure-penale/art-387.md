# Article 387
Si la Chambre de Contrôle de l’Instruction estime que les faits constituent un délit ou une contravention, elle prononce le renvoi de l’affaire dans le premier cas devant le Tribunal correctionnel, dans le second cas devant le Tribunal de Police.
En cas de renvoi devant le Tribunal de Police, le prévenu est mis en liberté.
