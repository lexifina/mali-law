# Article 412
Les décisions de non-lieu et, lorsqu’elles sont motivées par une insuffisance de charges, de classement sans suite font l’objet d’une mention, sauf si le Procureur de la République ordonne l’effacement des données personnelles.
Les autres décisions de classement sans suite font l’objet d’une mention.
Lorsqu’une décision faite l’objet d’une mention, les données relatives à la personne concernée ne peuvent faire l’objet d’une consultation dans le cadre des enquêtes administratives.
