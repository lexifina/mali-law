# Article 458
Si les délais ci-dessus prescrits n’ont pas été observés, les dispositions énoncées ci-après sont applicables :
1- dans le cas où la partie citée ne se présente pas, la citation doit être déclarée nulle par le Tribunal ;
2- dans le cas où la partie citée comparait, la citation n’est pas nulle mais le Tribunal doit, sur la demande de la partie citée, ordonner le renvoi à une audience ultérieure.
Cette demande doit être présentée avant toute défense au fond.
