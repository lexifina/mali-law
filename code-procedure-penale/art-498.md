# Article 498
Lorsqu’à raison d’un même crime, plusieurs ordonnances de renvoi ont été rendues contre différents accusés, le Président peut, soit d’office, soit sur réquisition du Ministère public, ordonner la jonction des procédures.
Cette jonction peut également être ordonnée quand plusieurs ordonnances de renvoi ont été rendues contre un même accusé pour des infractions différentes.
