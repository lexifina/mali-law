# Article 742
Le Tribunal compétent en matière de reddition de compte est :
 pour les comptables commis par justice, le tribunal qui les aura commis ;
 pour les tuteurs, le tribunal du lieu où la tutelle a été déférée ;
 pour tous autres comptables, le tribunal de leur domicile.
La procédure de reddition de compte obéira aux règles établies pour la marche de l’instance devant le tribunal civil.
