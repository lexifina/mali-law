# Article 211
L’Ordonnateur tient une comptabilité administrative qui décrit les opérations suivantes :
- la constatation des droits acquis contre les débiteurs ;
- l’engagement, la liquidation et le mandatement des dépenses budgétaires.
La comptabilité administrative permet de connaître :
- les crédits ouverts et les prévisions des recettes ;
- les crédits disponibles pour les engagements ;
- les crédits disponibles pour les mandatements ;
- les dépenses réalisées et les recettes réalisées ;
- l’emploi fait des recettes grevées d’affectation spéciale.
