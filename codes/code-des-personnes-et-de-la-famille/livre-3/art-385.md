# Article 385
Les régimes matrimoniaux règlent les effets patrimoniaux du mariage dans les rapports des époux entre eux et à l’égard des tiers.
Le présent Code organise différents régimes :
- la séparation des biens ;
- la communauté universelle ;
- la communauté réduite aux acquêts ;
- les autres communautés convenues entre les époux.
