# Article 138
Dans toutes les entreprises agricoles, la durée légale de travail ne peut excéder quarante-huit heures par semaine.
Les heures accomplies au-delà de cette durée hebdomadaire donneront lieu à défaut de convention collective ou d’accord d’entreprise ou d’établissement aux majorations minima suivantes :
 10 % pendant les heures supplémentaires de travail de jour effectuées au-delà de 48 heures,  50 % pendant les heures supplémentaires de nuit.
Les heures supplémentaires effectuées les jours de repos hebdomadaire ou les jours fériés donneront lieu à une majoration de 50 % pour les heures de jour et de 100 % pour les heures de nuit.
