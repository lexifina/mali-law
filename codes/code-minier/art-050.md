# Article 50
La liste des équipements et matériels qui peuvent être utilisés pour l’exploitation artisanale est fixée par le décret d’application du présent Code.
L’utilisation des explosifs et des substances chimiques dangereuses, notamment le cyanure, le mercure et les acides dans les activités d’exploitation artisanale, est interdite. Le travail des enfants est interdit dans les activités d’exploitation artisanale.
