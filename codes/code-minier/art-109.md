# Article 109
Les substances de carrière, qu’elles se trouvent sur un terrain privé ou sur le domaine de l’État, ne peuvent être exploitées qu’en vertu :
a) d’une autorisation d’ouverture de carrière délivrée par les Collectivités territoriales pour les carrières artisanales ;
b) d’une autorisation d’exploitation de carrière délivrée par le ministre chargé des Mines pour les carrières industrielles.
