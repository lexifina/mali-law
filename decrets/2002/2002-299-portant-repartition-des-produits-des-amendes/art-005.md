# Article 5
Le produit disponible des amendes, pénalités, frais de poursuite sera réparti comme suit :
- Budget national= 67 % - Caisse des Retraites = 5 % - les 28 % restants sont répartis entre :
- les Agents de renseignements ;
- les Ayants droit ou auteurs de pénalités ;
- le Fonds Spécial d’Equipement des Services ;
- le Fonds Commun ;
- les Responsables.
