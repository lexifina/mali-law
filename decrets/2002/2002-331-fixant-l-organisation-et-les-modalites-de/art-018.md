# Article 18
Le Conseil Scientifique est composé comme suit :
Président : Le Directeur Général ;
Membres :
- Le Directeur Général Adjoint ;
- Les chefs des Départements de Recherche ;
- Les Directeurs de Recherche ;
- Les Directeurs des Institutions Nationales de Recherche ou leurs représentants ;
- Les représentants des O.N.G. impliquées dans les recherches en Sciences Sociales.
