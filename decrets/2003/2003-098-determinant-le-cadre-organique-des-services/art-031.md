# Article 31
La section renseignements opérationnels est chargée de :
- traiter toutes les questions relatives à la documentation opérationnelle des Armées ;
- tenir la situation des études effectuées dans le domaine opérationnel par l’Etat-Major des Armées ;
- tenir une documentation de renseignements sur les Armées étrangères ;
- établir les plans de renseignements qui couvrent les besoins de l’Etat-Major des Armées dans le domaine opérationnel.
