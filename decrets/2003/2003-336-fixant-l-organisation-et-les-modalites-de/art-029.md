# Article 29
Le comité technique d’hygiène et de sécurité comprend deux (2) représentants élus par chacune des catégories suivantes :
- odonto-stomatologues, pharmaciens ;
- assistants médicaux ;
- techniciens supérieurs ;
- auxiliaires de santé ;
- agents administratifs ;
- agents de surface ;
- techniciens d’hygiène ;
- agents sociaux.
