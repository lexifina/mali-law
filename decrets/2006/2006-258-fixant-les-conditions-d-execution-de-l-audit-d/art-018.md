# Article 18
Au cours du constat d’audit, l’équipe d’audit :
- examine toutes les preuves d’audit pour déterminer les points de non conformité par rapport aux critères d’audit ;
- s’assure que les constats d’audit de non conformité sont consignés dans un document de façon claire et concise ;
- analyse lesdits constats avec le responsable de l’audit afin qu’il prenne acte de la base réelle de tous les constats de non conformité.
