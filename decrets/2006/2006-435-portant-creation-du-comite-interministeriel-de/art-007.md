# Article 7
Le dossier est soumis à l’approbation des autorités de tutelle ci-après :
- le Préfet : dans le cas de deux ou plusieurs communes d’un même cercle ;
- les Préfets concernés : dans le cas de deux ou plusieurs communes appartenant à des Cercles différents ;
- le Gouverneur de région :
·dans le cas de deux ou plusieurs communes du même Cercle avec le Cercle ;
·dans le cas de deux ou plusieurs Cercles appartenant à la même Région.
- les Gouverneurs de Régions concernées : dans le cas de deux ou plusieurs Cercles de Régions différentes ;
- le Ministre chargé des collectivités territoriales :
·dans le cas de deux ou plusieurs Cercles d’une même Région et la Région ;
·dans le cas de deux ou plusieurs Régions ;
·dans le cas d’une ou plusieurs Régions avec le District de Bamako.
