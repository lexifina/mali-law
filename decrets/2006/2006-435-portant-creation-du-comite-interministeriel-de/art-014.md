# Article 14
Les statuts du syndicat déterminent :
- les domaines d’intervention ;
- la composition ;
- l’organisation et les modalités de fonctionnement ;
- la dénomination et l’aire d’intervention ;
- la durée ;
- le siège ;
- les modalités de convocation des réunions ;
- le nombre de vice-président ;
- les modalités d’adhésion ;
- les ressources.
