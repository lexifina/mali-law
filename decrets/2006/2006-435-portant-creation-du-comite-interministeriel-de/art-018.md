# Article 18
Le secrétaire permanent est l’agent principal d’exécution du syndicat. Il assiste le président dans la gestion administrative et financière du comité.
Le secrétaire permanent est chargé de :
- préparer les réunions du Comité ;
- tenir les procès – verbaux et les cosigner avec le président ; -conserver et classer les archives du Comité ;
- rédiger les correspondances et les actes juridiques ;
- préparer le programme d’activité, le budget, les états financiers du Comité ;
- exécuter les décisions du Comité.
