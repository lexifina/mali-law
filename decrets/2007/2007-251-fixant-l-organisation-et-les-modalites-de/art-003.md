# Article 3
Les Centres d’Apprentissage Agricole sont composés des organes suivants :
- le Conseil de Perfectionnement ;
- la Direction ;
- le Conseil Pédagogique ;
- le Conseil de Discipline ;
- le Comité de Gestion.
Outre les organes ci-dessus cités, les Centres d’Apprentissage Agricole comprennent des Enseignants.
