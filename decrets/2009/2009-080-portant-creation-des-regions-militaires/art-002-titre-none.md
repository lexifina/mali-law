# Article 2 (Titre None)
Le ressort territorial des régions militaires est fixé comme suit :
- Région Militaire N°1 : Région de Gao ;
- Région Militaire N°2 : Région de Ségou ;
- Région Militaire N°3 : Région de Koulikoro et District de Bamako ;
- Région Militaire N°4 : Région de Kayes ;
- Région Militaire N°5 : Région de Tombouctou ;
- Région Militaire N°6 : Région de Mopti ;
- Région Militaire N°7 : Région de Kidal;
- Région Militaire N°8 : Région de Sikasso.
