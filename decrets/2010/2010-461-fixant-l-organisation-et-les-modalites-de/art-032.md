# Article 32
Le domaine du Centre de Formation Pratique en Aquaculture de Molodo est composé comme suit :
- les bâtiments du bloc administratif ;
- les bureaux des formateurs ;
- les salles de classe et de travaux pratiques ;
- les logements du personnel ;
- les dortoirs et annexes ;
- les stations ;
- les étangs ;
- le laboratoire ;
- la bibliothèque ;
- le terrain de sport.
