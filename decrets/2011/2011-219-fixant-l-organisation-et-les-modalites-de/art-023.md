# Article 23
Le Conseil de Discipline est composé comme suit :
* Président : le Directeur du Lycée Sportif Ben Omar SY ;
* Rapporteurs :
- le Directeur des Etudes et de la Formation Sportive ;
- le Surveillant général ;
* Membres :
- le Chef du Centre Médical ;
- quatre (04) représentants du corps enseignant désignés pour un an par
- leurs collègues ;
- deux (02) représentants des élèves désignés pour un an par leurs pairs ;
- trois (03) représentants des entraîneurs désignés par leurs pairs pour
- un an ;
- deux (02) représentants des parents d’élèves désignés pour un an par les - parents.
