# Article 7
Le Centre de Documentation et de l’Informatique est chargé de :
- gérer la documentation et les archives du service ;
- collecter, traiter diffuser les textes réglementaires nationaux et communautaires touchant le secteur industriel ;
- gérer la base de données industrielles ;
- développer les supports de diffusion de l’information industrielle ;
- diffuser l’information industrielle.
