# Article 3
Les indemnités allouées aux fonctionnaires de la Protection Civile sont :
* l’indemnité de représentation et de responsabilité ;
* l’indemnité de mission ;
* l’indemnité de déplacement ;
* l’indemnité de caisse et de gestion ;
* l’indemnité de contrôle et de vérification ;
* la rémunération pour heures supplémentaires de travail ; * l’indemnité de résidence ;
* l’indemnité de cherté de vie ;
* l’allocation de stage ;
* les allocations familiales ;
* l’indemnité de logement ;
* l’indemnité spéciale de solidarité.
