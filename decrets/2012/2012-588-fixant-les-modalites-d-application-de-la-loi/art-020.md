# Article 20
Les établissements privés qui ne respectent pas les normes requises s’exposent aux sanctions suivantes :
1. l’avertissement écrit ;
2. le blâme avec ampliation à tous les établissements ;
3. la suspension de l’autorisation d’ouverture pendant au moins deux ans ;
4. le retrait de l’acte d’autorisation de création, d’ouverture ou de diriger.
