# Article 64
Les bénéficiaires de la répartition sont :
- œuvres musicales: l’auteur, le compositeur, le parolier, le chanteur (interprète), l’adaptateur, l’arrangeur, l’éditeur, le sous éditeur, l’instrumentiste, le choriste, le chorégraphe ;
- œuvres littéraires : l’auteur, le traducteur, l’adaptateur, l’éditeur, le narrateur, le conteur, le déclamateur, le metteur en scène, l’illustrateur, le photographe ;
- œuvres dramatiques, dramatico-musicales, interprétations et exécutions audiovisuelles, cinématographiques : l’auteur, le traducteur, l’adaptateur, le scénariste, le dialoguiste, le chorégraphe, le réalisateur, l’acteur, le comédien ;
- œuvres d’arts : le sculpteur, le dessinateur, le peintre, le photographe, l’architecte, l’éditeur, l’adaptateur, l’auteur de copie.
