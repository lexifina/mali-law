# Article 67
Lorsque les œuvres mentionnées sur les fiches d’exploitation sont déclarées, tous les ayants droit sont bénéficiaires de droits. Dans le cas contraire, les bénéficiaires sont ceux dont les noms figurent sur les fiches d’exploitation.
Toutefois, lorsqu’un ayant droit est mentionné sur la fiche d’exploitation alors qu’aucune indication de titre permettant d’identifier l’œuvre n’y ressort, cette fiche est purement et simplement écartée.
