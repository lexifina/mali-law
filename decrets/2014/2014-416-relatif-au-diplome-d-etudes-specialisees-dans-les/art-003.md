# Article 3
Le dossier de demande d’ouverture du D.E.S doit comporter :
1. la description du contexte et la justification du D.E.S ;
2. les objectifs ;
3. les conditions d’inscription ;
4. les modalités d’organisation de la formation ;
5. les ressources humaines. Il s’agit :
- des curricula vitae des enseignants intervenant dans la formation ;
- de la liste des enseignants et des encadreurs de stage ;
- des actes de nomination dans leurs grades respectifs ;
- des partenariats ou conventions pour les enseignants étrangers ;
6. les procédures d’évaluations ;
7. le budget de la formation ;
8. les ressources financières ;
9. la description des infrastructures ;
10. la description du plateau technique.
