# Article 27
Les critères de sélection des candidats aux postes vacants sont :
1. Diplôme universitaire du postulant ;
2. Formations reçues en cours d’emploi ;
3. Appréciation des chefs hiérarchiques du fonctionnaire ; 4. Ancienneté dans le corps admissible pour le poste ;
5. Nombre d’années passées dans les services d’appui ; 6. Durée des séjours dans les Directions régionales.
