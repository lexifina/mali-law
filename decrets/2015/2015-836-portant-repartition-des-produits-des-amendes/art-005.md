# Article 5
Le produit disponible des amendes, confiscations, pénalités, frais de poursuites sera reparti comme suit :
* Budget national :
50 % ;
* Caisse des retraites :
5 % ;
* Les 45 % restants sont repartis entre :
- les agents de renseignements ;
- les ayants-droit ou auteurs des pénalités ;
- le fonds spécial d’équipement des services ;
- le fonds commun ;
- les responsables.
