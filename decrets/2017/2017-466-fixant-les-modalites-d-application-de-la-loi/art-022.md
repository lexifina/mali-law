# Article 22
L’apprentissage est régi par un contrat écrit entre l’employeur en qualité de maître d’apprentissage et l’apprenti ou son tuteur légal, conformément aux dispositions du code du travail en matière d’apprentissage. Il est sanctionné par un certificat. Toutefois, dans le cadre du contrat d’apprentissage relatif aux apprentis dans l’artisanat, seront observées, les dispositions du Code communautaire de l’UEMOA suivant le Règlement n°01/ 2014/CM/ UEMOA portant Code Communautaire de l’Artisanat de l’Union Economique et Monétaire de l’Afrique de l’Ouest.
