# Article 11
L’Unité de Gestion du Projet est composée comme suit :
- le Coordonnateur du projet ;
- un (01) Responsable spécialiste chargé des questions de ligne et poste ;
- un (01) Responsable chargé des questions de Qualité-Sécurité-Environnement ;
- un (01) Responsable chargé des questions de suivi-évaluation ;
- un (01) Responsable chargé des questions de génie civil ;
- un (01) Agent chargé de l’administration et de la Comptabilité ;
- un (01) Responsable chargé des questions juridiques ; - un (01) Contrôleur Sénior travaux postes ;
- un (01) Technicien Contrôleur Travaux ligne HTA/BT ; - un (01) Technicien Contrôleur Travaux poste ;
- un (01) Technicien Contrôleur Travaux ligne HTB ; - un (01) Technicien supérieur Contrôleur Travaux Génie civil-ligne.
L’Unité de Gestion du Projet est assistée d’un personnel d’appui composé comme suit :
- un (01) Secrétaire ;
- un (01) Chauffeur ;
- un (01) Planton.
L’Unité de Gestion du Projet peut se faire assister par toute autre compétence au niveau des structures relevant du ministère chargé de l’Energie.
