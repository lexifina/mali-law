# Article 105
Il est mis fin au congé de formation dans les cas suivants :
- l’indiscipline ;
- l’insuffisance de résultats ;
- le changement d’orientation sans autorisation préalable ;
- les raisons de santé ;
- sur demande du stagiaire.
Le redoublement d’une année est interdit sauf cas de force majeure dûment justifié.
