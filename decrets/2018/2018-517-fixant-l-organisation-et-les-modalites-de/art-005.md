# Article 5
Les Missions diplomatiques et consulaires comportent selon les cas, les postes suivants :
- Ambassadeur ;
- Ambassadeur Représentant permanent ;
- Ambassadeur, Représentant Permanent Adjoint ;
- Ambassadeur Délégué permanent ;
- Ministre conseiller ;
- Conseiller d’Ambassade;
- Attaché de défense ;
- Conseiller culturel ;
- Conseiller à la Communication ;
- Consul général/ Consul ;
- Vice consul ;
- Conseiller consulaire ;
- Chargé de protocole ;
- Secrétaire d’ambassade ;
- Secrétaire agent comptable ;
- Agent consulaire.
