# Article 28
Les titres délivrés pour l’exploitation et la circulation des produits de pêche comprennent :
- les Permis de Pêche ;
- les Autorisations de Pêche dans le domaine piscicole de l’Etat ;
- les Autorisations de Pêche dans le domaine piscicole des Collectivités territoriales ;
- l’Autorisation gratuite de Capture d’Alevins dans le milieu naturel ;
- le Certificat d’Origine ;
- le Certificat de Conditionnement ;
- le Certificat d’Origine d’Exportation.
