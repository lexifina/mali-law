# Article 7
Les Bureaux comptables secondaires sont créés au niveau ci-après :
- les directions centrales ;
- les services déconcentrés (régionaux et locaux) ; - les services rattachés ;
- les Cercles (Cercles et ses services administratifs) ; - les Ambassades ;
- les Consulats généraux ;
- les Unités de gestion de projets ;
- les Unités de gestion de projets de programmes.
