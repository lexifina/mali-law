# Article 2
Les voies navigables sont classées en trois (03) catégories :
a) première catégorie : les cours principaux sont le Fleuve Niger et le Fleuve Sénégal ;
b) deuxième catégorie : les cours secondaires adjacents sont les affluents et défluents des fleuves ;
c) troisième catégorie : les canaux aménagés.
