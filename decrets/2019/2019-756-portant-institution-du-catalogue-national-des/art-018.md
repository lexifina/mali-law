# Article 18
Le Catalogue national donne les caractéristiques morphologiques et physiologiques permettant de distinguer entre elles les variétés végétales cultivées.
Il comprend pour chaque espèce ou variété inscrite, les rubriques suivantes :
- dénomination de la variété ;
- description générale de la variété ;
- caractéristiques d’identification ;
- caractéristiques agronomiques et technologiques ;
Les éléments de chaque rubrique sont consignés dans les RTE.
