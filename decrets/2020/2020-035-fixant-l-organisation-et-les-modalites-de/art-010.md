# Article 10
L’UCNP est composée comme suit :
• En staff :
- le Service d’Audit et de Contrôle interne ;
- le Secrétariat ;
• En ligne :
- le Département administratif et financier ;
- le Département technique PRAPS-ML ;
- le Département technique PADEL-M ;
- le Département Suivi Evaluation ;
- le Département Passation des Marchés ;
- les Coordinations régionales.
