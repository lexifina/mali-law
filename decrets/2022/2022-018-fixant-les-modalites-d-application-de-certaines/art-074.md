# Article 74
Pour l’attribution du code de l’établissement, les informations suivantes sont exigées :
- nom de la structure de santé ;
- statut de l’établissement ;
- spécialités exercées ;
- adresse complète ;
- Relevé d’identité bancaire.
Pour l’attribution du code du praticien, les informations suivantes sont exigées :
- nom de la structure de santé d’appartenance ;
- nom et prénoms du praticien ;
- spécialité(s) exercée(s) ;
- le numéro d’enregistrement à l’ordre professionnel ;
- adresse complète.
