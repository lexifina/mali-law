# Article 7
L’Assemblée générale est constituée de trente (30) membres du CNDS.
Elle délibère sur :
- le projet de règlement intérieur ;
- le projet de budget ;
- le projet de programme d’activités annuel ;
- la création de commissions spécialisées ;
- les cas de saisine ou d’auto-saisine ;
- le projet de rapport sur l’état du dialogue social ; - le projet de rapport d’activités annuel ;
- la révocation d’un membre ;
- les états financiers du Conseil ;
- la désignation de Commissaires aux Comptes.
