# Article 13
Le Comité ministériel spécialisé « Développement » est composé ainsi qu’il suit :
1. Président : le ministre chargé de l’Economie.
2. Vice-président : le ministre chargé du Commerce.
3. Membres :
- le ministre chargé des Finances ;
- le ministre chargé des Transports ;
- le ministre chargé de l’Education nationale ;
- le ministre chargé de l’Enseignement supérieur ; - le ministre chargé des Mines ;
- le ministre chargé de la Santé ;
- le ministre chargé de l’Action humanitaire ;
- le ministre chargé de l’Industrie ;
- le ministre chargé de la Jeunesse ;
- le ministre de l’Agriculture ;
- le ministre chargé de l’Energie ;
- le ministre chargé de l’Eau ;
- le ministre chargé de l’Emploi ;
- le ministre chargé de la Promotion de la Femme ; - le ministre chargé de l’Environnement ;
- le ministre chargé de l’Elevage ;
- le ministre chargé de la Culture.
