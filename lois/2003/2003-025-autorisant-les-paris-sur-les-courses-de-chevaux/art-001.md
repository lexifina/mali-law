# Article 1er
Sont autorisés sous les conditions de la présente loi les paris sur les courses de chevaux et les jeux de hasard suivants :
- la loterie classique ;
- les jeux de grattage ou loterie instantanée ;
- le millionnaire ;
- le loto ;
- le loto sportif ;
- bingo ;
- tac O tac ;
- keno ;
- banco.
