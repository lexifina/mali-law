# Article 49
Les congés sont des périodes interruptives de service assimilées à l’activité. Les congés comprennent:
- le congé annuel ;
- le congé de maladie ;
- le congé de formation ;
- le congé d’expectative ;
- le congé d’intérêt public ;
- le congé spécial ;
- le congé de maternité ;
- le congé pour raisons familiales.
