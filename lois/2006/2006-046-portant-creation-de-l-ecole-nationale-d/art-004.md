# Article 4
Les ressources de l’E.N.A sont constituées par :
- les subventions de l’Etat ;
- les revenus provenant des prestations de service ;
- les dons et legs ;
- les subventions autres que celles de l’Etat ;
- les concours de partenaires techniques et financiers ;
- les emprunts ;
- les frais pédagogiques ;
- les ressources diverses.
