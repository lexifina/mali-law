# Article 41
Les titres comprennent :
* les titres délivrés dans le cadre de l’exercice de la pêche :
- la carte d’exploitant de pêche;
- le permis de pêche;
- les autorisations de pêche.
* les titres délivrés dans le cadre du commerce international :
- le certificat d’origine;
- le certificat de conditionnement;
- les certificats d’origine d’exportation;
- le certificat d’exportation;
- le certificat de réexportation.
