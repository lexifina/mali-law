# Article 113
Les cas d’ouverture à pourvoi sont:
1. l’incompétence ;
2. le vice de forme ;
3. le vice de procédure ;
4. la violation de la loi ;
5. le détournement de pouvoir ;
6. le défaut de réponse à un moyen soulevé ;
7. la perte de fondement ;
8. la contrariété de jugements ;
9. Le défaut de base légale.
