# Article 21
Au sens de la présente loi, on entend par autorités compétentes, les autorités ci-après :
- les Ambassadeurs, les Consuls généraux ;
- les Procureurs généraux ;
- les Procureurs de la République ;
- les Commandants de Brigade ;
- les Commissaires de Police ;
- les Préfets - les Sous-préfets ;
- les Maires.
