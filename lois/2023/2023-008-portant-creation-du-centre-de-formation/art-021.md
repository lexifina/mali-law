# Article 21
Le Comité de Gestion est composé par :
- le Directeur général ;
- le Directeur général adjoint ;
- le Surveillant général ;
- les Chefs d’Ateliers ;
- les Chefs de Cellule ;
- les Chefs d’Unité ;
- les Chefs des Travaux ;
- le Chef du Secrétariat ;
- l’Agent comptable ;
- le représentant des utilisateurs du Centre.
