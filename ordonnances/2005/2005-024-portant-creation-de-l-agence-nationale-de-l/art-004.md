# Article 4
Les ressources de l’Agence Nationale de l’Aviation Civile sont constituées par :
- les redevances aéronautiques ;
- les produits des prestations pour services rendus ;
- les produits des redevances de concession ;
- les subventions de l’Etat ;
- les emprunts ;
- les dons et legs ;
- les concours financiers des organismes nationaux et étrangers ;
- les recettes diverses.
