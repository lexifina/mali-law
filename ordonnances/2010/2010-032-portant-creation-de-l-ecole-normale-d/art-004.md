# Article 4
Les ressources de l’ENETP sont constituées par :
- les subventions de l’État ;
- les subventions d’organismes et d’entreprises publics ou privés, nationaux ou étrangers ;
- les fonds d’aides extérieures ;
- les revenus financiers ;
- les revenus provenant de prestations de service ;
- les dons et legs ;
- les emprunts ;
- les revenus provenant de droits d’inscription et des frais pédagogiques ;
- les recettes diverses.
