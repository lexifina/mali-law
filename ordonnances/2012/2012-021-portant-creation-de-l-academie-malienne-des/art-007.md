# Article 7
Le Conseil d’Administration de l’Académie est composé de :
Membres avec voix délibérative :
- représentants des pouvoirs publics ;
- représentants des usagers des langues nationales ;
- représentant du personnel
Membres avec voix consultative :
- le Directeur Général de l’Académie ;
- les responsables des structures techniques de l’Académie ;
- l’agent comptable.
