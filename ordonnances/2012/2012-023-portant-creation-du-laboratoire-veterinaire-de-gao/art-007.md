# Article 7
Le Conseil d’Administration est composé de :
- les représentants des pouvoirs publics ;
- les représentants des services régionaux ;
- les représentants des collectivités territoriales ;
- les représentants des organisations professionnelles ;
- les représentants des usagers ;
- le représentant du personnel du Laboratoire Vétérinaire de Gao.
