# Article 26
Les congés autorisés sont ceux limitativement énumérés ci-après :
- le congé annuel ;
- le congé de maladie ;
- le congé de maternité ;
- le congé de formation ;
- le congé sabbatique ;
- le congé d’expectative ;
- le congé d’intérêt public ;
- le congé spécial ;
- le congé pour raisons d’ordre familial.
