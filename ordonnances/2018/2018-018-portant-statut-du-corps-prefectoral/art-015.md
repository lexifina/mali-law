# Article 15
Les congés sont des périodes interruptives de services assimilées, en principe, à l’activité.
Les congés autorisés sont :
- le congé annuel ;
- le congé de maladie ;
- le congé de maternité ;
- le congé de formation ;
- le congé d’expectative ;
- le congé d’intérêt public ;
- le congé spécial ;
- le congé pour raisons familiales.
